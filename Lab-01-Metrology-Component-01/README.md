# Lab 01: Precision Metrology & Geometric Verification

## Project Objective
The mission objective is to perform manual measurements of physical industrial castings and translate them into production-ready digital configurations using precision metrology and parametric CAD modeling.

## Engineering Constraints & Criteria
- **Validation Dossier**: A strict 3-page validation PDF is required.
- **Page 1**: Signed hand-drawn sketch containing manual physical measurements.
- **Page 2**: SolidWorks solid model screenshot featuring the student ID card.
- **Page 3**: Technical drawing screenshot, also featuring the student ID card.

## Methodology & Execution Steps
1. **Physical Auditing**: Measure the assigned physical casting using calibrated vernier calipers and produce a detailed hand drawing.
2. **Parametric Modeling**: Transfer the physical dimensions into SolidWorks to create an accurate 3D solid model.
3. **Drafting**: Generate standardized technical geometric projections from the solid model.

## Toolchain & Software Used
- Calibrated Vernier Calipers
- SolidWorks

## Acquired Engineering Competencies
- Precision manual measurement and drafting
- Parametric 3D solid modeling
- Technical drawing generation and geometric verification
