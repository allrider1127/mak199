# Lab 04: Optical Scanning - Dental Prosthesis

## Project Objective
The mission objective is to conduct an optical scan of a dental prosthesis using the EinScan SE-SP V2 scanner, generate a watertight STL mesh, and perform volumetric structural analysis.

## Engineering Constraints & Criteria
- **Validation Report**: A documented PDF report is required.
- **Visual Evidence**: Must include a group photograph taken during the scanning process.
- **Analysis Documentation**: Must include a SolidWorks/Meshmixer analysis screenshot featuring the student ID.
- **Geometric Data**: Exact values for model weight, volume, and surface area must be calculated and presented.

## Methodology & Execution Steps
1. **Optical Capture**: Perform 3D scanning of the dental model.
2. **Mesh Generation**: Export the scanned point cloud data as a solid STL file.
3. **Volumetric Analysis**: Import the STL into Meshmixer or SolidWorks to compute mass properties.

## Toolchain & Software Used
- EinScan SE-SP V2
- SolidWorks / Meshmixer

## Acquired Engineering Competencies
- Reverse engineering and optical scanning operations
- STL mesh generation and processing
- Structural mass property and volumetric evaluation
