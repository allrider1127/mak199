# MAK 199 (CRN 24268) - Engineering Metrology & Additive Manufacturing

## Project Objective
This repository contains the technical documentation and industrial case studies for MAK 199. The curriculum spans manual metrology, 3D optical scanning, and advanced additive manufacturing methodologies.

## Engineering Constraints & Criteria
- **Validation**: All physical artifacts are backed by signed validation sheets and full 3D interactive models.
- **Traceability**: Digital twins are maintained on OnShape with stringent version control.
- **Quality Assurance**: 3D scanning and printing iterations are documented with dimensional verification against standard reference models.

## Toolchain & Software Used
- **CAD & Parametric Modeling**: SolidWorks, OnShape
- **Slicing & Additive Manufacturing**: FlashPrint
- **Mesh Manipulation**: Meshmixer
- **Optical Metrology**: EinScan SE-SP V2
